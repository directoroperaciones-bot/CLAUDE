# Banco de fotos — copia de la página original

`index.html` es la página del **Banco de fotos Caminos**
(https://claude.ai/artifact/WPzKkP7MwdKBaGrrGVpZ1Y) tal como estaba antes de
publicar en ese mismo enlace la app de documentos (versión 1790383250-2f90,
contrato 0.2.59, capacidades `assets` y `db`).

Las fotos no están aquí: viven en la base de datos (colección `fotos`) y en los
archivos de esa página, y siguen ahí. Para volver a la página original basta con
publicar este `index.html` en el mismo enlace con las capacidades
`{"assets": {}, "db": {}}`; los datos no se tocan.
